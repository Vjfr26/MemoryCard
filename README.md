# Memory Card

Juego de memoria para el navegador, hecho con Phaser 3: aventura de 9 niveles contra el reloj, duelo contra la IA o un amigo y modo libre.

## Jugar

```bash
python3 -m http.server 8000
```

Abre <http://localhost:8000>.

Se juega con clic o toque, o con las flechas y Enter.
